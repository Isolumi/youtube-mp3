# yt-dlp 403 Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore complete YouTube audio downloads by updating and locking yt-dlp.

**Architecture:** Keep the existing FastAPI and GitOps design. Add a build-time
version gate to the backend image, then update the declared and locked yt-dlp
version so the same container build moves from red to green.

**Tech Stack:** Python 3.12, uv, yt-dlp, Docker, GitHub Actions, GHCR, Kustomize, Argo CD

**Spec:** `docs/superpowers/specs/2026-08-23-yt-dlp-403-fix.md`

## Global Constraints

- Minimum supported yt-dlp version: `2026.08.19`.
- Keep `uv sync --frozen --no-dev` as the image installation path.
- Do not change the frontend or API contract.
- Deploy only through the existing `development` branch GitOps workflow.

---

### Task 1: Lock and verify the fixed downloader

**Files:**
- Modify: `backend/Dockerfile`
- Modify: `backend/pyproject.toml`
- Modify: `backend/uv.lock`

**Interfaces:**
- Consumes: The existing uv-managed backend environment.
- Produces: A backend image whose installed yt-dlp version is at least `2026.08.19`.

- [ ] **Step 1: Add the build-time version gate**

Add a `RUN` command after `uv sync` that imports the real installed package and
fails when its parsed date version is less than `(2026, 8, 19)`.

- [ ] **Step 2: Run the backend image build to verify red**

Run: `docker build -t yootoob-mp3-api:yt-dlp-red ./backend`

Expected: FAIL because the lockfile installs `2026.07.04`.

- [ ] **Step 3: Update the declared dependency and lockfile**

Change the dependency floor to `yt-dlp>=2026.8.19`, then run:

```bash
cd backend
uv lock --upgrade-package yt-dlp
uv sync --frozen --no-dev
```

- [ ] **Step 4: Run local verification**

Run:

```bash
cd backend
uv run python -c "import yt_dlp; assert tuple(map(int, yt_dlp.version.__version__.split('.'))) >= (2026, 8, 19)"
uv run python -m compileall -q main.py
cd ..
docker build -t yootoob-mp3-api:yt-dlp-green ./backend
cd frontend
bun run lint
bun run build
cd ..
kubectl kustomize k8s/overlays/dumachine >/dev/null
```

Expected: all commands exit `0`.

- [ ] **Step 5: Commit**

```bash
git add backend/Dockerfile backend/pyproject.toml backend/uv.lock \
  docs/superpowers/specs/2026-08-23-yt-dlp-403-fix.md \
  docs/superpowers/plans/2026-08-23-yt-dlp-403-fix.md
git commit -m "fix: update yt-dlp for YouTube downloads"
```

- [ ] **Step 6: Publish and verify production**

Push the feature branch, merge it into `development`, wait for the image and
tag update workflow, verify Argo CD is Healthy and Synced, and submit the same
video through the public API. Poll the returned job until it is `complete` and
confirm the result endpoint returns an MP3 response.
