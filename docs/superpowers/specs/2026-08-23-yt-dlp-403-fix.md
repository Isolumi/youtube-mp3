# yt-dlp 403 Fix Specification

## Problem

The live site and API are healthy, but `yt-dlp 2026.07.04` selects YouTube's
broken `android_vr` client and fails complete audio downloads with HTTP 403.

## Required result

- The backend image must contain `yt-dlp 2026.08.19` or newer.
- The dependency must remain locked by `uv.lock` and installed with
  `uv sync --frozen`.
- The image build must fail if the installed version is older than
  `2026.08.19`.
- The normal `development` branch workflow must publish and deploy the image.
- A complete live API download must finish successfully after deployment.

## Scope

Do not change the frontend, API contract, Kubernetes topology, or storage model.
